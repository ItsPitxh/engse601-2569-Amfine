# Shared Templates

- `ai-use-declaration.md` — ใช้เมื่อ AI ช่วยวิเคราะห์/ร่าง/ตรวจทาน
- `peer-review-record.md` — บันทึก reviewer, finding, disposition และ re-check
- `evidence-register.md` — ทะเบียนหลักฐานจริง/แผน/ช่องว่างที่ใช้ข้ามสัปดาห์
- `decision-and-open-issue-log.md` — decision, owner, due และผลกระทบต่อกิจกรรมถัดไป

คัดลอก template ไปไว้ใน `WEEKS/week-XX/work/` เมื่อจำเป็น อย่าแก้ไฟล์ต้นฉบับกลางจนทำให้สัปดาห์ก่อนหน้าเปลี่ยนความหมาย
