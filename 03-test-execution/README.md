## ขั้นต่ำ

- เลือกระดับให้ทุกกรณีทดสอบในชุดอ้างอิง พร้อมเหตุผลว่าพฤติกรรมอยู่ที่ไหน
- อัตโนมัติ 1 ข้อ ระดับ Unit หรือ API พร้อมผลการรันจริง · ทีมที่ไม่ใช้ JavaScript ใช้ pytest JUnit หรือเครื่องมือของภาษานั้นได้
- System ทำมือ 1 ข้อ พร้อมภาพหน้าจอ
- สถานการณ์ UAT 1 เรื่อง รันจริงหรือ Not Executed พร้อมแผน
- ตารางผลของทุกข้อ ทุกแถวมีสถานะและหลักฐาน

รันไม่ได้ ให้บันทึก Not Executed พร้อมเหตุผล และวางโค้ดที่เขียนแล้วใน `tests/` ได้คะแนนตามเกณฑ์
